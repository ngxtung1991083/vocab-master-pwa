VOCAB MOBILE WEB APP V1 - HUONG DAN SU DUNG

1. Cai Python 3.10+ tren may tinh.

2. Giai nen thu muc nay.

3. Mo CMD/Terminal tai thu muc app va chay:

   pip install -r requirements.txt

4. Chay app:

   python app.py

5. Mo tren may tinh:

   http://127.0.0.1:5000

6. Mo tren dien thoai cung Wi-Fi:

   http://IP-MAY-TINH:5000

   Vi du:
   http://192.168.1.10:5000

7. Dang nhap mac dinh:

   Username: tung
   Password: 123456

8. Doi mat khau:

   Mo file app.py, tim dong:
   APP_PASSWORD = "123456"

   Doi thanh mat khau rieng cua ban.

9. File Excel import can co cac cot:

   Hán tự / Hanzi / Chinese
   Pinyin
   Tiếng Việt / Vietnamese / Viet
   English

10. Cai nhu app tren dien thoai:

   Android:
   Chrome -> dau 3 cham -> Them vao man hinh chinh

   iPhone:
   Safari -> Chia se -> Them vao Man hinh chinh

Luu y bao mat:
- Ban nay chi nen dung trong Wi-Fi rieng.
- Khong mo cong router ra internet neu chua them HTTPS va bao mat nang cao.
